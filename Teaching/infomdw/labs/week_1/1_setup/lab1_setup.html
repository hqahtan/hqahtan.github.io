Know Your Tools

Overview

During this lab, you will get familiar with the most important tools that will be used during the course. These tools include (SQLite), DB Browser, and Google Colab for Python.

SQLite and DB Browser

In this course, we will use SQLite and its graphical interface DB Browser to create and query DBMSs. As an example database in this lab, we will use the Chinook database.

To download the database files, open the sample databases link and look for Chinook_Sqlite.sqlite and Chinook_Sqlite.sql. Right-click the link and choose Save Link As… to download the database file.

macOS

On macOS, SQLite is built in. Open your terminal, navigate to your working directory, and create a database:

shell$ sqlite3 Chinook

This creates Chinook.db in the working directory. Verify it:

sqlite3sqlite3> .databases

Expected output:

Outputmain: /Users/.../Chinook r/w

Import the tables from Chinook_Sqlite.sql:

sqlite3sqlite3> .read Chinook_Sqlite.sql
Note: Make sure Chinook_Sqlite.sql is in your current working directory, or provide the full path.

Loading the database takes a few seconds. Once the database is loaded, you can list the tables using:

sqlite3sqlite3> .tables

If the database is uploaded correctly, you should see these 11 tables:

AlbumEmployeeInvoiceLine PlaylistTrackArtistGenre MediaTypeTrackCustomer InvoicePlaylist

If you downloaded Chinook_Sqlite.sqlite (a binary file) instead, use .open rather than .read, that is :

sqlite3sqlite3> .open Chinook_Sqlite.sqlite

Alternatively: 

shell$ sqlite3 Chinook_Sqlite.sqlite

Windows

For MS-Windows user, download the file sqlite-tools-win-x64-3460100.zip from the SQLite website at this link and store it at a specific location (let us say infomdwr/lab0/).

shell$ sqlite3 Chinook
