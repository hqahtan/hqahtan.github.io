Assignment 2: Paper Summarization--Data Preparation

In this assignment, you need to review a paper about one of the data-preparation technique, and reproduce the main results reported in the paper:

⚠Generative AI tools

This assignment assesses your ability to understand research work and provide informed feedback on it.

You may not use generative AI tools, such as ChatGPT or Claude, to summarize the paper or to write feedback or criticism of the proposed technique. You may use such tools to help implement the algorithm if no suitable code is available online. However, you are fully responsible for the correctness of the implementation. You must understand the code, verify its results, and fix any errors it may contain.

Task 1: paper review (50% for tasks 1 and 2)

  1. Select a paper that proposes an algorithms for a data-preparation technique. Possible topics include:

    1. Data cleaning: outlier detection, functional dependencies for data cleaning, missing value imputation, disguised missing values, entity resolution.

    2. Data reduction: principal component analysis, independent component analysis, matrix factorization, locally linear embedding (LLE), isomap, UMAP, and sampling.

    3. Data transformation: Trifacta, and OpenRefine.

    4. Data profiling.

    5. Schema matching and alignment.

  2. Read the paper carefully and write a summary of no more than two pages. Your summary should include:

    1. The main problem addressed in the paper.

    2. The proposed solution.

    3. Any optimization techniques or special cases discussed in the paper.

    4. The strengths and limitations in the paper.

    5. The evaluation methodology.

  3. Highlight the sections of the paper that contain the information used in your summary. The summary must be written in your own words and must not reproduce sentences from the paper. Copying complete sentences constitutes plagiarism and will result in zero points for this assignment. Submit the highlighted paper together with your summary.

Task 2: Reproducing the results

To complete this task, you need an implementation of the main algorithm described in the paper. If the authors have not made their code available and no suitable implementation exists in a Python library, you must implement the algorithm yourself. You may use generative AI tools to assist with the implementation. Make sure that the implementation is correct and produces results that can be meaningfully compared with those reported in the paper.

  1. Select and reproduce the main experiment reported in the paper.

  2. Compare your results with the results reported in the original paper.

  3. List all parameters required to run the code and specify the values used.

  4. If there are substantial differences between your results and those reported in the original paper, explain the possible reasons for those differences.

Task 3: Providing feedback to other students (50%)

Each student will receive three submissions selected at random. You must review these submissions and provide constructive feedback. Consider the following aspects:

  • The quality of the report, including English usage, critical discussion, and the soundness of the results.

  • The depth of the discussion

  • The completeness of the instructions for running the code, including commands and parameter settings.

  • An overall grade for the submission on a scale from 1 to 10.

Task 4: Responding to the received feedback

After receiving the feedback, provide a response for the comments from the evaluators of your work. You need also to mention if the comments are useful or not and to what extend.

Submission

This assignment consists of multiple submissions:

  1. Report submission: Submit a PDF file containing a paper summary of no more than two pages, followed by no more than two pages presenting the reproduced results, discussion, parameter settings, and a link to the code. If you reimplement the algorithm, upload the code to a GitHub repository and include the repository link in your report.

  2. Feedback submission: You will be randomly assigned three submissions to review. Submit your feedback through BrightSpace.

  3. Feedback-on-feedback submission: After receiving feedback, you may submit a response to each review and evaluate the quality and usefulness of the feedback.

Deadline

  • Feedback submission: 28 October 2026 at 23:59.
