SQLite & DB Browser

Setup instructions for SQLite, DB Browser, and Google Colab — using the Chinook sample database.

Overview

In this course, we will use SQLite and its graphical interface DB Browser to create and query DBMSs. As an example database, we will use the Chinook database.

To download the database files, open the sample databases link and look for Chinook_Sqlite.sqlite and Chinook_Sqlite.sql. Right-click the link and choose Save Link As… to download them.

SQLite3

🍎 macOS

On macOS, SQLite is built in. Open your terminal, navigate to your working directory, and create a database:

shell$ sqlite3 Chinook

This creates Chinook.db in the working directory. Verify it:

sqlite3sqlite3> .databases

Expected output:

main: /Users/.../Chinook r/w

Import the tables from Chinook_Sqlite.sql:

sqlite3sqlite3> .read Chinook_Sqlite.sql
Note: Make sure Chinook_Sqlite.sql is in your current working directory, or provide the full path.

After a few seconds, list the tables:

sqlite3sqlite3> .tables

You should see these 11 tables:

AlbumEmployeeInvoiceLine PlaylistTrackArtistGenre MediaTypeTrackCustomer InvoicePlaylist

If you downloaded Chinook_Sqlite.sqlite (a binary file) instead, use .open rather than .read:

shell$ sqlite3 Chinook_Sqlite.sqlite
🪟 Windows

Download sqlite-tools-win-x64-3460100.zip from sqlite.org/download and extract it into a folder such as infomdwr/lab0/sqlite.

Open Windows PowerShell and navigate to the sqlite folder containing the executables. Then follow the same steps as macOS, but prefix with ./:

powershell> ./sqlite3 Chinook

All subsequent commands (.databases, .read, .tables, etc.) are identical to macOS.

DB Browser

🗄️ DB Browser (GUI)

In DB Browser you can use the graphical interface to work with the Chinook database.

To import from Chinook_Sqlite.sql, go to File → Import → Database from SQL file…, select the file, and choose No when asked to create a new database. If successful, the table count will change from 0 to 11.

To verify, open the Execute SQL tab and run:

sqlSELECT name FROM sqlite_schema
WHERE type = 'table'
  AND name NOT LIKE 'sqlite_%';

The result will be a table listing all 11 database tables.

Google Colab for Python

For simplicity, we will use Google Colab for running Python programs. If you prefer another IDE (Anaconda, PyCharm, Spyder), feel free to use it — but be aware that specific libraries may require a particular Python version.

🐍 Google Colab

Create a new notebook and check the installed Python version:

python!python --version

To install a specific Python version (e.g. 3.7):

python!apt-get install python3.7

Installing Libraries

Most important libraries are pre-installed in Colab. To add extras, use pip:

python!pip install py_stringmatching
Note: The ! prefix runs system commands inside any notebook environment.
